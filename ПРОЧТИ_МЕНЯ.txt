Сборка APK через GitHub

Нужные файлы (все лежат прямо в корне репозитория, папки для работы не нужны):
  main.py, icons_data.py, icon.png, buildozer.spec
  .github/workflows/main.yml   (запускает сборку)
Папка tools не обязательна.

1. Загрузи эти файлы в репозиторий (Add file -> Upload files).
   Старые файлы с такими же именами будут заменены.
2. Вкладка Actions -> Run workflow. Сборка 20-40 минут.
3. Внизу запуска в разделе Artifacts скачай .apk, скинь на телефон и установи.
